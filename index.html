Why this read

Nothing here is population-ranked. The game uses only this run: routes, distance, ink, timing, solved rules, ordered recall, tracked targets, and the final return path. A skipped part stays labeled as missing evidence or friction—it is never silently scored as a failure. Hints shown are kept as context, not counted as mistakes. A label summarizes a move; the evidence beneath it shows why. One run can reveal a play style, not define a person.
